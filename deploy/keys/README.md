# Доступ к серверу стенда ЦДА

**Приватные ssh-ключи в репозитории НЕ хранятся и не коммитятся**
(репозиторий публичный; паттерны ключей — в .gitignore). Рабочая пара
ключей роя передаётся между запусками по защищённому каналу и лежит
вне git.

## Хелпер

`sshx.py` — выполнение команд на сервере через paramiko (ssh-клиента
в системе нет). Путь к приватному ключу — через env `CDA_KEY`:

    export CDA_KEY=/путь/к/id_ed25519
    python3 deploy/keys/sshx.py "cmd"
    python3 deploy/keys/sshx.py put <локальный> <удалённый>

## Деплой

    CDA_KEY=... python3 deploy/deploy_remote.py
