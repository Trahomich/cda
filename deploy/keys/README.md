# Доступ к серверу стенда ЦДА

**Важно: приватный ssh-ключ в репозитории НЕ хранится** (репозиторий
публичный). В репо лежит только публичная часть ключа (`id_ed25519.pub`)
и хелперы.

## Файлы

- `id_ed25519.pub` — публичная часть ключа (не секрет).
- `sshx.py` — хелпер выполнения команд на сервере через paramiko
  (ssh-клиента в системе нет).

## Приватный ключ

Передаётся вне git (секретный канал). При запуске укажите путь в env:

    export CDA_KEY=/путь/к/id_ed25519

## Использование

- SSH-команды на сервере: `CDA_KEY=... python3 deploy/keys/sshx.py "cmd"`,
  копирование файлов: `CDA_KEY=... python3 deploy/keys/sshx.py put <локальный> <удалённый>`.
- Деплой: `CDA_KEY=... python3 deploy/deploy_remote.py`.
- Контейнеры стенда: `deploy-api-1` (API, `/srv/app`), `deploy-db-1`
  (PostgreSQL, `psql -U cda -d cda`), `deploy-frontend-1`.

Сервер: cda.oblaka.pw (192.168.99.201, пользователь cda).
