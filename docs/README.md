# Проект ИС «Цифровой двойник агронома» (ЦДА) — сводка документации

Статус: готово · Версия: 1.0 · Дата: 2026-11-05 · Автор: Светлана Куликова

Аннотация. ЦДА — информационная система для растениеводческого хозяйства (КФХ/агрохолдинга),
которая собирает данные о полях, севообороте, удобрениях и СЗР, технике, животноводстве,
погоде и спутниковых снимках в единую модель и помогает агроному планировать и объяснять
решения. Пользователи: агроном (основной), руководитель, механизатор, зоотехник/ветеринар,
администратор. Ядро ценности: замкнутый контур «поля → план → работа → факт → данные/алерты»
с проверками бизнес-правил на каждом шаге, объяснимыми рекомендациями и мобильным полевым
клиентом (PWA) с офлайн-работой. Рекомендации вычисляет rules-engine на данных хозяйства
(ADR-04); внешний ИИ-ассистент не обязательный, работает локально на открытых весах и данные
не покидают контур хозяйства (ADR-05). Документация описывает проект: реализация — по этапам
дорожной карты (docs/08-roadmap.md): MVP → v1 → v2.

## 3. Краткие выводы

- Стек (02 §7): Python/FastAPI; PostgreSQL 18 + PostGIS (единая БД, ADR-02); Redis + очередь
  задач для адаптеров; веб — SPA (фреймворк фиксируется при старте), мобильный — PWA (ADR-03);
  контейнеры. Архитектура — модульный монолит с внутренней шиной событий (ADR-01),
  рекомендации — rules-engine на нормализованных данных (ADR-04), ИИ — локальный модуль за
  API (ADR-05).
- Состав MVP (08 §1): агрономический контур — поля и контуры, севооборот с проверками,
  справочник и планы СЗР/удобрений (без расчёта доз), журнал работ, погода и погодные окна,
  NDVI по Sentinel-2, парк техники и задания, PWA с офлайн-очередью, журнал адаптеров.
  Критерий готовности: SC-01, SC-03, SC-04 на реальном сезоне ≥1 месяц (пилот).
- Главные риски (08 §5, RISK-01..10): облачность NDVI (REC-17), деградация внешних API,
  качество телематики, невалидированные справочники нормативов, отсутствие GPU для чата,
  конфликты офлайн-синхронизации, доверие агрономов к рекомендациям — у каждого риска есть
  митигация.
- Открытые вопросы пользователю (08 §6): режим ИИ-железа (CPU/GPU), пилотное хозяйство и
  регион, телематика-интегратор, развёртывание (облако/контур), объём животноводства в v1,
  доступность данных о ценах для v2-экономики. Ответы нужны до старта реализации.

## 4. Состояние исследований

Оба исследования завершены и встроены в проект (08 §7): выбор источников MVP —
research/02 (REC-16 Open-Meteo, REC-17 Sentinel-2, REC-18 импорт агрохимии, REC-19
редактируемые справочники, REC-20 CSV/ISOXML-импорт телематики); продуктовые ориентиры —
research/01 (карточка поля и NDVI-алерты, животноводческо-полевой контур, нормативы РФ,
объяснимость как дифференциатор, REC-01..15). Открытый пункт: мини-исследование
животноводческих ИС перед стартом v1 (research/01 §5) — не блокирует MVP.

подсистема в 03–07/09–10. Термины — glossary.md; правила ведения документов — CONTRACTS.md.
