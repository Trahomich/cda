# Глоссарий проекта ЦДА

Статус: готово · Версия: 1.0 · Дата: 2026-11-05 · Автор: Иван Куликов

Единый источник терминов проекта (CONTRACTS.md §3). Новые термины добавляют авторы
документов по мере необходимости. Формат: термин | определение | синонимы.

| Термин | Определение | Синонимы |
|---|---|---|
| ЦДА | «Цифровой двойник агронома» — проектируемая ИС управления хозяйством | — |
| Хозяйство | Сельскохозяйственное предприятие, для которого ведётся цифровой двойник | предприятие, с/х организация |
| Поле | Учётная сельхозземля с контуром (границей) и площадью в га | участок |
| Контур поля | Геометрическая граница поля в формате GeoJSON Polygon, WGS84 | граница, полигон |
| Севооборот | Научно обоснованное чередование культур на полях во времени | ротация |
| Культура | Сельхозкультура, возделываемая на поле в сезоне (пшеница, ячмень, ...) | — |
| Пар | Поле, свободное от посева в течение сезона для восстановления плодородия | чистый пар |
| Предшественник | Культура, возделывавшаяся на поле в предыдущем цикле | — |
| Возврат культуры | Минимальный интервал лет между повторным посевом той же культуры на поле | ротация культуры |
| Удобрение | Вещество для питания растений; доза измеряется в кг д.в./га | — |
| д. в. | Действующее вещество; для удобрений — N, P2O5, K2O и микроэлементы | действующее вещество |
| N-P-K | Основные элементы питания: азот (N), фосфор (P2O5), калий (K2O) | макроэлементы |
| Вынос питательных элементов | Количество N-P-K, выносимое урожаем культуры с 1 га (кг д.в./га) | вынос |
| СЗР | Средства защиты растений: пестициды (гербициды, фунгициды, инсектициды) | пестициды, средства защиты |
| Срок ожидания СЗР | Минимальный интервал между обработкой и уборкой урожая (дней) | период ожидания, карентный срок |
| Обработка | Технологическая операция с применением СЗР или удобрений | опрыскивание, внесение |
| Погодное окно | Интервал времени, когда погодные условия допускают полевую операцию | окно |
| NDVI | Нормализованный разностный вегетационный индекс (−1..1) — «зелёность» посева | вегетационный индекс |
| NDRE | Индекс красной кромки; чувствителен к состоянию густого посева и азоту | — |
| Агрохимия почвы | Результаты анализа почвы: pH, гумус, подвижные N-P-K, микроэлементы | почвенное обследование |
| Валовой сбор | Объём собранной продукции (т или ц) | урожай |
| Урожайность | Валовой сбор с единицы площади (ц/га) | — |
| Операция (на поле) | Технологическая работа на поле: вспашка, посев, обработка, уборка | полевая работа |
| Техника | Тракторы, комбайны, опрыскиватели и др. машины хозяйства | МТА (агрегат) |
| Телематика | Данные бортовых ГЛОНАСС/GPS-мониторов техники: треки, скорость, расход | мониторинг техники |
| Стадо | Совокупность животных хозяйства; делится на группы | — |
| Группа животных | Учетная группа: сухостой, дойное стадо, молодняк, откорм | технологическая группа |
| Рацион | Набор и количество кормов на голову в сутки, питательность в ЭКЕ | кормление |
| ЭКЕ | Энергетическая кормовая единица (10 МДж обменной энергии) | — |
| Навоз | Органическое удобрение из отходов животноводства; доза в кг д.в./га | органика |
| Алерт | Автоматическое оповещение системы о событии или риске | оповещение |
| Рекомендация | Предложение системы о действии (доза, срок, операция) с обоснованием | совет |
| Адаптер | Программный модуль подключения внешнего источника данных (CONTRACTS §7) | коннектор |
| MVP | Минимально жизнеспособный продукт — первый реализуемый этап ЦДА | — |
| MoSCoW | Шкала приоритетов: Must / Should / Could / Won't | приоритет |
