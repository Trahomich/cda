# 2. Источники данных для ИС «Цифровой двойник агронома»

**Статус:** черновик v1.0 · **Дата:** 2026-11-05 · **Автор:** Татьяна Новикова (задача #3)

**Назначение документа.** Каталог внешних и внутренних источников данных для ИС ЦДА по подсистемам цели: поля — севооборот — удобрения и СЗР — техника — животноводство — погода — спутниковый мониторинг. Для каждого источника указаны способ доступа, формат, периодичность, покрытие, лицензия и риски. В итоговом разделе — рекомендованный состав источников для MVP (REC-01…) и отложенные источники. Документ используется задачами интеграций и дорожной карты; он самодостаточен и читаем без дополнительного контекста.

**Методика.** Источники описаны по собственным знаниям автора на ноябрь 2026 г. Доступность ключевых API проверена реальными HTTP-запросами 2026-11-05 из тестового окружения (см. примечания «проверено запросом»). Российские ресурсы из тестового окружения часто недоступны технически — такие факты помечены «требует проверки». IDs рекомендаций и стиль — по CONTRACTS.md (§4); на момент написания CONTRACTS.md ещё не опубликован, поэтому используется формат REC-NN, при необходимости будет выровнен с контрактом.

### 2.2. Вегетационные индексы (для спутникового мониторинга)

| Индекс | Формула (по каналам) | Что показывает | Когда применять | Особенности |
|---|---|---|---|---|
| **NDVI** | (NIR−Red)/(NIR+Red) | «Зелёная биомасса», общее развитие посевов | Весь сезон, основной индекс | Насыщается при высокой биомассе (LAI>3–4); сильно искажается почвой на ранних фазах |
| **NDRE** | (NIR−RedEdge)/(NIR+RedEdge) | Содержание хлорофилла/азота в «плотном» посеве | Поздние фазы, диагностика азотных подкормок | Требует канала Red Edge (Sentinel-2 есть, Landsat — нет) |
| **NDMI** | (NIR−SWIR)/(NIR+SWIR) | Влажность растительности, стресс/созревание | Мониторинг засухи, время уборки | Хорошо коррелирует с водным статусом посева |
| **SAVI** | ((NIR−Red)/(NIR+Red+L))·(1+L), L≈0.5 | NDVI с поправкой на яркость голой почвы | Ранние фазы, разреженные всходы | L — коэффициент; вариант EVI тоже применим |
| (доп.) **NDWI (вода)**, **Thermal** | SWIR/Green; тепловые каналы | Влажность почвы/водный стресс | Доп. диагностика | Thermal — Landsat (100 м), Sentinel-3 |

Практика ЦДА: NDVI как основной индекс сезона; NDRE — для азотных подкормок (важно для подсистемы «удобрения»); SAVI — весной; NDMI — к уборке. Продукты уровня L2A (Sentinel-2) уже с атмосферной коррекцией; вычисление индексов ЦДА ведёт сам по каналам или берёт готовые продукты (например, MOD13 у MODIS).

### 2.3. Проблема облачности и повторяемости съёмки

- Оптические сенсоры (Sentinel-2, Landsat) не видят землю под облаками; в увлажнённых регионах РФ в мае–июле вероятность «чистого» снимка конкретного поля за 10–14 дней может падать до 30–50 % (оценка, зависит от региона — требует проверки по конкретным областям).
- Смягчение: (а) композитирование за 10–14 дней («лучший пиксель»); (б) Sentinel-1 (радар, сквозь облака) — для факта всходов/влажности; (в) MODIS — частые, но грубые снимки для тренда; (г) gap-filling/интерполяция временного ряда NDVI в ЦДА; (д) коммерческая досъёмка (позже).
- Вывод: спутниковый блок ЦДА обязан проектироваться как временные ряды с композитами, а не «снимок на дату».

### 3.2. Состав MVP в одну строку

**MVP = Open-Meteo (погода) + Sentinel-2 через Copernicus (индексы по полям) + импорт агрохимии/почв + внутренний справочник нормативов + импорт телематики CSV/ISOXML.** Всё бесплатное или уже принадлежащее хозяйству; каждый источник закрыт обратной совместимостью с ручным вводом.

## 4. Открытые вопросы

1. Подтвердить на площадке заказчика доступность и регламент API: ФСПИ, Гидрометцентр РФ, Росреестр, Ветис (REC-10).
2. Требуется экспертиза агронома для валидации справочника выноса N-P-K по региону хозяйства (влияет на REC-04).
3. Какой интегратор телематики у целевых хозяйств (Wialon/Omnicomm/иное) — уточнить у заказчика для приоритизации прямых API (REC-05).
