# Экономика производственной модели ЦДА (пост-MVP, этап v2)

Статус: черновик · Версия: 1.0 · Дата: 2026-11-05 · Автор: Иван Куликов

Решение пользователя: экономика **не входит в MVP**; этап v2 по 08-roadmap §3
(REQ-F-033) расширяется животноводством и переработкой. Документ фиксирует
проектное решение и методику расчёта, чтобы v1 не создал данных, не пригодных
для калькуляции. Опирается на docs/01-requirements.md (REQ-F-033, новый §3.10),
docs/03-domain-agronomy.md (ENT-FIELD-OPERATION, ENT-AGRO-INPUT, ENT-CROP-CYCLE),
docs/04-domain-farm.md (ENT-RATION, ENT-PRODUCTION-RECORD, ENT-VET-EVENT,
ENT-MANURE-YIELD), docs/05-integrations.md (IF-PRICES, ref_price),
docs/06-data-api.md (DAT, API), docs/08-roadmap.md §3.

## 1. Назначение и границы

Экономический блок превращает производственный план и факт в деньги: калькуляция
затрат и себестоимости по полям, культурам, группам животных, партиям переработки;
оценка эффекта рекомендаций; P&L-отчёт хозяйства за период. Источник данных — уже
нормализованные записи ЦДА (ADR-04): экономика не заводит свои журналы работ.

За границами блока: бухгалтерский и налоговый учёт (1С и т. п.), зарплата и
кадры, кредиты/лизинг, продажи и логистика реализации. ЦДА — управленческий
(производственный) учёт, обмен с бухгалтерией — экспорт API-32, не интеграция.

## 2. Сценарии (EC-NN)

| ID | Сценарий | Успех |
|---|---|---|
| EC-01 | Калькуляция затрат цикла: по культурному циклу собираются затраты из фактов операций, СЗР/удобрений, работ техники | сумма руб/цикл и руб/га сходится с ручной проверкой ±2 % |
| EC-02 | Себестоимость продукции растениеводства: затраты цикла ÷ урожай (ENT-YIELD-RECORD), план vs факт | руб/т по полю и культуре; отклонение плана от факта показано |
| EC-03 | Экономическая оценка рекомендации (расширение REQ-F-033): дельта затрат и выручки в карточке | у рекомендации с ценами виден эффект в руб.; без цен — блок скрыт |
| EC-04 | Экономика животноводства: день содержания группы, себестоимость л молока / ц привеса | руб/л и руб/ц по группе за месяц; корма — из фактов рациона |
| EC-05 | Переработка: партия сырья (молоко) → выход продукции (нормы расхода) → себестоимость и маржа | по партии видны выход, себестоимость руб/ед. и маржа по ценам реализации |
| EC-06 | P&L хозяйства: выручка − затраты по направлениям (растениеводство/животноводство/переработка) за период | отчёт за месяц по всем трём направлениям с детализацией до поля/группы |

## 3. Модель калькуляции

### 3.1. Состав затрат и источники

| Категория | Источник факта в ЦДА | Как превращается в деньги |
|---|---|---|
| ГСМ | dat_field_operation / dat_machine_job (площадь, ч работы) | норма л/га или л/ч (ENT-COST-RATE) × цена топлива (ref_price) |
| Амортизация и ТО | наработка машины из dat_machine_job, dat_maintenance | ставка руб/мото-ч (ENT-COST-RATE) |
| Труд | исполнитель и часы в dat_field_operation | ставка руб/ч по роли |
| Удобрения и СЗР | позиции плана/факта внесения (03 §1.5) | доза × цена ref_price (item=input) |
| Корма | факты рациона dat_ration × headcount | кг × цена ref_price (feed, вводится как input) |
| Ветеринария | dat_vet_event | стоимость из события |
| Переработка | затраты партии (ENT-PROCESSING-BATCH) | прямые + распределённые |

Принцип: **прямые затраты** привязаны к циклу/группе/партии автоматически;
**общие** (зарплата управления, ГСМ перегонов) распределяются пропорционально
площади (растениеводство) или голам (животноводство) — коэффициенты задаёт
экономист хозяйства, по умолчанию равномерно. Пользователь может ввести затрату
вручную (ENT-COST-ITEM с source=manual) — она помечается в отчёте.

### 3.2. План vs факт

Плановые затраты считаются той же методикой по планам (dat_treatment_plan,
плановым операциям, плановому рациону), фактические — по фактам. Отчёт EC-02/EC-06
всегда показывает пару план/факт и топ-3 отклонения с data_refs на исходные записи.

### 3.3. Цены

Единственный источник цен — ref_price (06 §3, IF-PRICES): закупка (input),
реализация (crop), справочно — корма и топливо. Нет цены → позиция показывается в
натуральных единицах с пометкой «нет цены», сумма не искажается. Средняя цена за
период — по дате операции.

## 4. Сущности и данные (дополняют 06-data-api.md §2)

### ENT-COST-RATE — норматив калькуляции

| Поле | Тип | Комментарий |
|---|---|---|
| id* | uuid | PK |
| kind* | enum | fuel_per_ha, fuel_per_hour, machine_hour, labor_hour, overhead_pct |
| ref_id | uuid | машина / культура / группа машин, null = общий |
| value* | decimal | л/га, л/ч, руб/ч, % — по kind |
| valid_from* | date | история ставок |

### ENT-COST-ITEM — рассчитанная или ручная затрата

| Поле | Тип | Комментарий |
|---|---|---|
| id* | uuid | PK |
| period* | date | месяц, к которому отнесена |
| target_type* | enum | crop_cycle, animal_group, processing_batch |
| target_id* | uuid | ссылка на цель |
| category* | enum | §3.1 (fuel, amortization, labor, inputs, feed, vet, processing, overhead) |
| amount* | decimal | руб., точность 2 |
| qty | decimal | натуральная величина (л, ч, кг) |
| source* | enum | calc (рассчитано из факта), manual |
| data_ref | uuid | запись-источник расчёта, null для manual |

### ENT-PROCESSING-BATCH — партия переработки

| Поле | Тип | Комментарий |
|---|---|---|
| id* | uuid | PK |
| date* | date | дата переработки |
| raw_type* | enum | milk (MVP-расширение: только молоко) |
| raw_qty* | decimal | кг сырья, источник — надои dat_production_record за период |
| product* | uuid | FK ref_product (новый: масло, творог, сухое молоко...) |
| yield_qty* | decimal | выход продукции, кг — по норме или факту |
| norm_ref | decimal | нормативный выход %, из справочника |

Таблицы: dat_cost_rate — UQ(kind, ref_id, valid_from); dat_cost_item —
IX(period, target_type, target_id), IX(category); dat_processing_batch —
UQ(date, product). Справочники: ref_product (переработка), ref_price расширяется
item_type=product. Пересчёт: dat_cost_item пересчитывается идемпотентно по
периоду (перерасчёт заменяет строки source=calc, manual не трогает).

## 5. API (дополняют 06-data-api.md §5, этап v2)

| ID | Метод и путь | Назначение | Трассировка |
|---|---|---|---|
| API-40 | GET /economics/crop-cycles/{id} | калькуляция цикла: план/факт, руб/га, руб/т | EC-01, EC-02 |
| API-41 | GET /economics/animal-groups/{id}?period | себестоимость группы (руб/л, руб/ц привеса) | EC-04 |
| API-42 | POST /processing/batches, GET /processing/batches | партии переработки | EC-05 |
| API-43 | GET /economics/pnl?period_from&period_to | P&L по направлениям с детализацией | EC-06 |
| API-44 | GET/POST /cost-rates | нормативы калькуляции | EC-01 |
| API-45 | POST /economics/recalculate | пересчёт периода (source=calc) | EC-01, EC-06 |

Ошибки — RFC 7807 §8 CONTRACTS: 422 `no_yield_record` (нельзя считать руб/т без
урожая), 404 по несуществующим целям. Расчёты синхронные (объём одного хозяйства
мал, REQ-NF-001), отдельной очереди не нужно.

## 6. Связь с ИИ-блоком (ADR-05)

AI-03-сводки (09-ai) расширяются экономическим разбором: «почему себестоимость
выше плана» по data_refs из dat_cost_item. Guardrail 09-ai §3 действует: ответ
только по данным ЦДА, цифры — со ссылками на записи.

## 7. Этапность внутри v2 (08-roadmap §3)

1. Цены и калькуляция цикла (EC-01..03) — «цены+экономика — M» по 08 §3.
2. Животноводство (EC-04) — после контура v1 (dat_ration, dat_production_record).
3. Переработка (EC-05) и P&L (EC-06) — по требованию хозяйства; стартует только
   при наличии переработки в хозяйстве (вопрос пользователю, аналог Q6).

## 8. Приёмка (проверяемо, этап v2)

1. Калькуляция цикла на демо-данных сезона сходится с контрольным расчётом
   экономиста ±2 % (протокол расчёта прилагается).
2. План/факт: у каждой позиции отчёта есть data_ref на исходную запись или
   пометка manual (проверка запросом).
3. Отсутствие цены не ломает отчёт: позиция в натуральных единицах (автотест).
4. Себестоимость молока за месяц по демо-группе: руб/л рассчитан из рациона,
   ветсобытий и труда; ручная проверка ±5 %.
5. Партия переработки: выход по норме и факту, себестоимость и маржа — по EC-05.
6. P&L за месяц по трём направлениям с детализацией до поля/группы.

## 9. Открытые вопросы

- Ставки амортизации и руб/мото-ч: вводит экономист хозяйства (ENT-COST-RATE) —
  нужны первичные значения на пилоте (данные бухгалтерии).
- Оценка запасов (семена, остатки удобрений) на начало/конец периода: упрощённо
  не учитываем (кассовая модель периода); признание запасов — v2+, вопрос к
  экономисту хозяйства.
- Переработка, кроме молока (зерно на муку и т. п.): не проектируем, ref_product
  позволяет добавить без смены модели.
