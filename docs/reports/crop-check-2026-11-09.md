## Метод и ограничения

- Класс — только ГРУППА (озимая/яровая зерновая, многолетние травы, пар); вид внутри группы по спутнику не определяется. Предложение культуры — доминирующая культура группы по записям севооборотов хозяйства (из справочника ref_culture), помечено «предположение по группе».
- Озимая: осенний подъём NDVI ≥ 0.35 (октябрь–декабрь года сева) и/или апрельский NDVI ≥ 0.3. Яровая: без осенней вегетации (max осени < 0.30 — стерня/сорняки после уборки яровых держат NDVI до ~0.3), один главный пик в мае–июле ≥ 0.40. Травы: укосные циклы — два и более пиков ≥ 0.45 с провалом ≥ 0.15 (низкий «пик» после провала — жнивье, не отрастание травы). Пар: max NDVI сезона < 0.30 (+ BSI голой почвы при наличии).
- Уверенность: 0.5·силы правила + 0.5·доли сезонов истории поля с тем же классом (мультисезонность 2023–2026).
- Сверка mismatch — только где группа по записи однозначна (озимые маркеры «озим/рожь/тритикале», травы «трав/люцерн/клевер/эспарцет/донник», kind=fallow). «Яровая зерновая» по спутнику не сверяется с видом яровой записи (пшеница/гречиха/кукуруза…).
- Ограничения: пар ни в одном сезоне не подтверждён спутником (на «парах» 2023 в записях спутник видит вегетацию — либо записи неверны, либо порог 0.30 занижен для сорняковых пар); сезоны без осенних сцен (2023 без октября–декабря 2022) классифицированы по апрельскому NDVI с пониженной уверенностью; 60 сезонов — uncertain (мало сцен или противоречивые признаки), вынесены в открытые вопросы.
