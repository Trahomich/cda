# Типовые техкарты (агрокалендарь) по группам культур — чернозёмная зона

Статус: готово · Версия: 1.0 · Дата: 2026-11-09 · Автор: Светлана Куликова
Задача: #158 (фидбек user #598: «работы должны соответствовать культуре сезона —
не бывает работ по яровым осенью и по озимым летом»). Машиночитаемая копия —
`docs/reports/tech-calendar-2026.json` (источник данных скрипта сверки #158).

## 1. Назначение и обоснование

Справочник типовых окон операций по группам культур для (а) разовой
актуализации планов и журнала работ стенда (#158) и (б) будущей автопроверки
планов при создании (отдельная задача). Зона — чернозёмная (стенд: ЦЧР/степь);
сроки — типовые агрономические, оценка «±10 дней» по погоде года.

Источники (открытые, проверены 2026-11-09):
- Wikipedia: статьи «Озимая пшеница», «Ячмень», «Рожь», «Тритикале», «Овёс»,
  «Гречиха», «Просо», «Кукуруза», «Горох», «Соя», «Подсолнечник», «Рапс»,
  «Люцерна», «Клевер», «Свёкла сахарная», «Картофель» (агротехника, сроки
  сева/уборки по зонам).
- Учебная норма растениеводства ЦЧР (Вавилов В.И. и др., «Растениеводство»):
  календарные сроки основных работ по группам культур; нормы ЦЧР/степи
  совпадают с описаниями в статьях выше.
Выбор «что взяли»: единая таблица по ГРУППАМ культур (а не по каждой культуре),
потому что скрипт сверки работает на уровне «операция × группа», а внутри
группы окна культур совпадают с точностью до 10–15 дней.

## 2. Привязка операции к сезону цикла

Цикл `dat_crop_cycle.year` — год уборки (правило #157/§8.2). Операция даты D
поля относится к циклу: месяц(D) ≤ 7 → цикл year(D); месяц(D) ≥ 9 → сначала
year(D)+1 (озимые под будущий сезон), затем year(D); август — оба кандидата.
Это же правило использует `current_culture_name` (ai_assistant/detectors.py).
