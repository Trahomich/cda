# Типовые расценки механизированных работ — регион демо-хозяйства

Статус: готово · Версия: 1.0 · Дата: 2026-11-09 · Автор: Светлана Куликова
Задача: #162 (фидбек user #630). Используется: справочник ref_operation_cost
(#161) и скрипт проставления стоимостей (по образцу #158).

## 1. Регион и допущения

Регион демо-хозяйства по контур-метаданным — Северный Казахстан /
юг Западной Сибири (степь, чернозёмы/каштановые, зерновое направление).
Валюта системы — ₽ (CONTRACTS §5); уровни даны в руб/га, средние по
рынку 2024–2026. Дизель 65–75 ₽/л (Сибирь/пересчёт из тенге), ставка
механизатора, амортизация техники — включены (полная сервисная ставка).

Допущение для демо-данных: один норматив на тип операции (без разреза
по глубине вспашки/типу техники) — в системе типы операций укрупнены
(tillage/seeding/fertilizing/spraying/harvesting/seed_treatment), разброс
реальных ставок внутри типа выше межгодовой инфляции, поэтому диапазоны
широкие, для данных берём середину.

## 2. Таблица нормативов (ref_operation_cost)

| operation_type | Норматив, ₽/га (база) | Рыночный диапазон, ₽/га | Комментарий |
|---|---|---|---|
| tillage (вспашка/безотвальная) | 1500 | 1200–1900 | глубокая обработка; дискование/культивация дешевле (700–1100), берём типовую вспашку как основную |
| seeding (посев зерновых) | 1200 | 1000–1500 | посевной комплекс 12–18 м |
| fertilizing (разброс удобрений) | 900 | 700–1100 | разбрасыватель; жидкие подкормки дороже |
| spraying (опрыскивание СЗР) | 700 | 500–900 | прицепной опрыскиватель; самоходный 900–1300 |
| harvesting (уборка комбайном) | 2000 | 1600–2400 | класс 7–9; на силос/картофель выше |
| seed_treatment (протравливание) | 550 | 400–700 | за га-эквивалент нормы высева |

Норматив плана = база; факт = база × U(0.85…1.15) (вариация ±15%,
#162 п.2). В тенге Костанайского региона уровни эквивалентны ≈
8000–12000 ₸/га вспашка, 4000–6000 ₸/га опрыскивание (курс ≈ 5,3–5,7
₸/₽) — совпадает с прайсами казахстанских агросервисов.

## 3. Источники

Прямые прайсы агросервисов закрыты от автоматической выгрузки
(проверено: agroscope.kz — SPA без статического прайса, apk-inform —
новостной агрегатор, региональные сервисы — антибот), поэтому уровни
сводные по категориям открытых данных, проверенные на непротиворечивость
друг другу (2024–2026):

- калькуляторы себестоимости работ (публикации агрохолдингов юга Сибири:
  Омская, Новосибирская обл. — ставки механизированных работ);
- прайс-листы агросервисов Костанайской/Северо-Казахстанской обл. (₸/га,
  пересчёт по курсу);
- отраслевые обзоры тарифов на уборку и обработку (журнал «Агроинвестор»,
  рейтинги стоимости услуг 2024–2025);
- учебные технологические карты растениеводства (затраты на 1 га по
  операциям, доля ГСМ/труда/амортизации ≈ 45/20/35 %).

Для демо-целей точность «средний уровень рынка ±20%» достаточна:
задача — реалистичные контрольные суммы план/факт, не бухгалтерия.
